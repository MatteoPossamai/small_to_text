# Context for Agents

This file gives context to any agent or tool working in this repo. Read it fully before proposing plans, generating code, or answering questions.

## Goals of the repo

Simple, private project for the user to build a training and inference system for a simple voice based neural network.
It is all done with C++ since the user is on a path to learn high performance software and hardware, and wanted to add a bit more knowledge for ML/AI to its curriculum.

This is not meant to become commercial or production at any point in time, but might be used in the user life, maybe on its phone or smartwatch (Pixel Phone and Watch).

Learning is much more important than a good outcome here. Hence nudge the user into the understanding of things, and do not just hand out the correct answer. Let's make it fun and intellectually engaging.

## Who is the user

The user is NOT an AI researcher, or an expert in machine learning of sort. He has the basics theoretical knowledge, but you should assume he does not know almost anything in that regard, and most of this project is done by first principle, without too much academic background. Hence, when interacting with the user, avoid complex terminology or assuming complete understanding of it. You can use the terminology only after you have explained it, such that the first principle framework can keep on being built. MAKING THINGS MORE COMPLICATED THAN THEY SHOULD BE IS RECIPE FOR DISASTER.
